# Decisões de arquitetura (ADRs)

Um ADR (Architecture Decision Record, formato de Michael Nygard) registra uma decisão de arquitetura: o contexto, o que foi decidido e as consequências. Ele explica por que o código é como é; o como está em [ARQUITETURA.md](../ARQUITETURA.md).

## Como acrescentar um ADR

1. Pegue o próximo número livre e crie `docs/adr/NNNN-titulo-em-kebab-case.md`.
2. Use as seções Título, Status, Contexto, Decisão e Consequências, com data.
3. Acrescente uma linha na tabela abaixo.
4. Nunca edite um ADR aceito. Para mudar uma decisão, crie outro ADR que a substitui, marque o antigo como "Substituído pelo ADR NNNN" e cite o antigo no novo.
